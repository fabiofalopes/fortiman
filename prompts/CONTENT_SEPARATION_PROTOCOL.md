# OpenCode Instance Separation Protocol
## For: Work Laptop Environment

**CONTEXT**: You are working in the fortiman repository at work. This repo should contain ONLY technical Fortinet/networking content. Personal reflections, career thoughts, and workplace therapy writing belong in the separate Work-Therapy-Archive in the Obsidian vault.

---

## BEFORE You Create or Edit Any File, Ask:

**Is this content about:**
- [ ] Technical configurations, scripts, or network architecture? → STAY IN FORTIMAN
- [ ] Personal feelings, career decisions, or workplace dynamics? → MOVE TO OBSIDIAN
- [ ] Mix of both? → SPLIT: Technical facts stay here, personal narrative goes to Obsidian

---

## RED FLAGS - Do NOT Save These in FortiMan:

- Career development reflections
- "How I feel about..." statements  
- Workplace people analyses
- Personal frustration venting
- Career transition plans
- Emotional processing about work situations
- Organization structure complaints
- "Therapy" style writing

## GREEN FLAGS - Keep in FortiMan:

- FortiOS CLI commands
- Network topology diagrams
- Python automation scripts
- Hardware specifications
- Technical troubleshooting procedures
- Configuration templates
- FortiLink documentation
- VDOM implementation guides

---

## Quick Checklist Before Saving:

```
□ Does this contain emotional language? → Move to Obsidian
□ Is this about specific people/personalities? → Move to Obsidian  
□ Does this describe my career goals? → Move to Obsidian
□ Is this about workplace politics? → Move to Obsidian
□ Is this objective technical documentation? → Keep in FortiMan
□ Does this contain code/commands/configs? → Keep in FortiMan
```

---

## If You Find Mixed Content:

1. **STOP** - Don't commit mixed personal/technical content
2. **EXTRACT** - Pull out technical facts, procedures, commands
3. **SPLIT** - Create two versions:
   - Technical version (facts only) → Save in fortiman/reports/
   - Personal version (feelings/context) → Note for Obsidian vault
4. **LINK** - Add comment: "Personal reflection in Obsidian: Work-Therapy-Archive/[file]"

---

## File Naming Convention:

**FortiMan (Technical)**:
- `fortigate_[model]_setup.md`
- `vdom_troubleshooting_guide.md`
- `switch_port_automation.py`

**Obsidian (Personal)**:
- `career_development_reflection.md`
- `workplace_dynamics_analysis.md`
- `crisis_processing_[date].md`
